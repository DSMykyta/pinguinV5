# Архів декоративних ефектів — 13 листопада 2026

**Статус:** тимчасово прибрано з активного `work` на прямий запит власника. Це папка «сміття» для можливого відновлення; **не** частина Vite-застосунку.

## Збережено без змін

- `src/ui/animated-gradient/` — CSS AnimatedGradient: 2 файли.
- `src/ui/cloud-gradient/` — WebGL CloudGradient, хмарка входу й Aurora: 2 файли.
- `src/ui/sparkles/` — Sparkles: 2 файли.
- `src/features/tools/animated-gradient-demo.js/.css` — тестові кнопки, модальне демо, Sparkles switch: 2 файли.
- `tests/e2e/animated-gradient.spec.js`, `cloud-gradient-aurora.spec.js`, `sparkles.spec.js` — три зняті E2E-специфікації.
- `docs/ui/animated-gradient.md`, `cloud-gradient.md`, `sparkles.md` — 3 технічні описи.
- `docs/research/animated-gradient.md`, `suno-canvas-gradient.md`, `modal-ambient-gradient.md` — 3 дослідження.

**Усього 17 файлів**, структура збережена відносно кореня репозиторію. Перенесення здійснено шляхом копіювання в цей каталог і видалення старих файлів лише після перевірки копій. Після відновлення шляхи та імпорти потрібно синхронізувати з актуальним кодом.

## Що прибрано з активної системи

1. Глобальні CSS-імпорти трьох декоративних ефектів із `src/main.js`.
2. Градієнтні кнопки, Aurora, іскри і їхні імпорти з `src/features/tools/index.js`.
3. Хмарку з `src/features/login-demo/index.js` і відповідні геометричні стилі — форма входу залишається працездатною.
4. Невикористовувані токени заголовка декоративного градієнта й іскор з `src/styles/tokens.css`.
5. E2E тести декоративних ефектів з активного `tests/e2e` та їхні згадки в документації.

**Не чіпали:** семантичні кольори main/secondary/tertiary, Wave Progress, Thinking Progress, Button Group, Dialog, звичайні CSS-градієнти, що належать UI-компонентам.

## Відновлення

Повернути потрібні файли з цієї папки на їхні початкові шляхи, підключити імпорти у `src/main.js` та споживачах, а за потреби відновити семантичні декоративні токени з історії Git. **Не** копіювати всі ефекти автоматично: можна відновити тільки один необхідний компонент. Обов'язково перевірити актуальність API й запустити `npm run check` / `npm run test:e2e`.

Папку `trash` не імпортувати у production-код. Не публікувати через Vercel.
