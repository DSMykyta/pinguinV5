# Pinguin Next

Новий модульний Pinguin у гілці `work`. Поточний опублікований сайт — `main`, незмінний V5 — `legacy`, резерв попереднього релізу — `reserve`.

## Реалізовано

- Єдиний тихий Shell без кольорового поділу областей.
- Глобальна ліва навігація; вкладки активної сторінки розміщені **під її пунктом меню**, а не по центру header.
- Універсальна шапка сторінок: назва зліва; справа — дієвий пошук і кнопка контекстного aside.
- Звичайний плаваючий aside або закріплена права колонка без зміни його вигляду.
- Тема з legacy, круглі кутові кнопки та глобальні tooltip.
- Перший демонстраційний маршрут `/tools` із вкладками «Таблиці» та «Текст» для перевірки навігації. `/` перенаправляє на `/tools`. Сторінки «Огляд» немає.

Редактори таблиць та тексту ще **не** перенесено. Наступний функціональний модуль — генератор таблиць.

## Запуск та перевірки

```bash
npm install
npm run dev
npm run check
npm run test:e2e
```

Не переносити `work` у `main` до перевірки й прийняття справжніх модулів користувачем.
