# Pinguin Next

Модульна перебудова сайту у гілці `work`. `main` — чинна опублікована версія; `legacy` — незмінний V5; `reserve` — резерв попереднього релізу.

## Поточний стан

- Єдиний Shell із п'ятьма зонами: ліва панель, шапка, основна область, правий aside та структурний footer 56px (порожній без контексту, із пагінацією та власним FAB на колекціях).
- Заголовок сторінки зліва; **видимий пошук і контекстна кнопка справа на його рівні**.
- Локальні текстові вкладки у спільному рядку **під заголовком**, не в sidebar.
- Основна робоча секція під вкладками, вирівняна за спільним лівим краєм.
- Закріплений aside відсуває робочу область, не змінюючи вигляд меню.
- Теми та глобальні tooltip адаптовано з legacy.
- Тестовий маршрут `/tools` із вкладками «Таблиці» і «Текст». `/` перенаправляє на нього. «Огляд» відсутній.

**У вкладці «Текст» є базовий Rich Text Editor** (форматування, редагований режим HTML, undo/redo), без додаткових npm-залежностей. Повноцінного генератора таблиць поки немає.

```bash
npm install
npm run dev
npm run check
npm run check:headers
npm run test:e2e
```

Робота відбувається тільки у `work`, без змін до `main`, `reserve` та `legacy`.
