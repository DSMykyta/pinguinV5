# Pinguin Next

Новий модульний робочий простір (гілка `work`). Старий сайт збережено в `legacy`, а `main` залишається Production.

## Статус

**Етап 01 — Pinguin Shell.** Реальна ліва навігація, головна область, контекстний aside, три режими теми та мобільні панелі. Жодної бізнес-логіки старого V5 й жодної підробленої функції таблиць.

- [Архітектура оболонки](docs/shell.md)
- [Стандарт неймінгу та компонентів](docs/conventions.md)
- [План модулів](docs/start-here.md)

## Запуск і перевірка

```bash
npm install
npm run dev
npm run check
```

`npm run check` перевіряє неймінг, модульні тести та збірку Vite. На `work` ті самі перевірки запускаються через GitHub Actions. Vercel Preview збирається автоматично.

### Наступний етап

Після візуальної перевірки Shell — спільні поля, меню і редаговані рядки, які стануть основою першого функціонального модуля `table-generator`.
