# Pinguin Next

Чисте модульне робоче середовище. Розробка лише в `work`; поточний сайт — у `main`, архів V5 — у `legacy`, резерв релізу — у `reserve`.

## Стан

Реалізовано мінімальний **Pinguin Shell**: єдине тло, ліва навігація, чотири кути керування, компактний правий popover, теми зі старого V5. Маршрути та типи сторінок підключені через реєстр. Сторінки «Огляд» і тестові «Інструменти» використовують один шаблон; редактори ще не реалізовані. Перший повноцінний модуль (генератор таблиць) ще не почато.

- [Правила архітектури й неймінгу](docs/conventions.md)
- [Принципи Shell](docs/shell.md)
- [Типи сторінок і навігація](docs/page-navigation.md)
- [Універсальний шаблон сторінок і CSS-межі](docs/universal-page-layout.md)
- [Наступні кроки](docs/start-here.md)

## Запуск

```bash
npm install
npm run dev
npm run check
npm run test:e2e
```

Після кожної зміни GitHub Actions виконує перевірки. Не переносити `work` у `main` без прийняття інтерфейсу та готової функціональності.
