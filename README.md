# Pinguin Next

**Стан: tabula rasa.** Чиста робоча основа без старих компонентів чи бізнес-логіки.

- `main` — поточна опублікована версія (Production).
- `reserve` — резерв попереднього стабільного релізу.
- `legacy` — незмінний знімок старого Pinguin V5.
- `work` — нова розробка, по одному модулю (Preview).

Зараз є лише стартова сторінка, точка входу JavaScript і мінімальне налаштування збірки Vite. Це **не новий дизайн і не реалізація інструментів**.

## Локальний запуск

```bash
npm install
npm run dev
npm run build
```

Спочатку разом погоджуємо оболонку та контракт модулів. Функції додаємо окремо, тільки після обговорення. Старий код не переноситься автоматично; за потреби його можна переглянути в `legacy`.
