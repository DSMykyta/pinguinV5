# Pinguin Next — відкритий концепт

Це робочі умови, а не затверджена технічна специфікація.

1. Гілка work починається з чистого дерева проєкту, без старих модулів.
2. Функції додаємо по одній після осмислення й погодження.
3. legacy зберігає старий V5; main — чинний Production; reserve — резерв релізу.
4. Старі CSS, генератори, API й JavaScript не імпортуємо автоматично.
5. Починаємо з обговорення оболонки та незалежності модулів.
6. Імена файлів, функцій, класів, подій та модулів повинні відповідати [єдиному стандарту](./conventions.md).

## Потребує рішення

- Навігація, центральна робоча область і правий aside.
- Контракт реєстрації та життєвого циклу модуля.
- Повна система дизайн-токенів, тем, відступів і адаптивності.
- Перший модуль — генератор HTML/BR-таблиць; перед реалізацією узгоджуємо модель рядка.

Жоден пункт не означає реалізації непогодженого функціоналу.
