# Дослідження — анімований градієнт із зернистістю

## Наявне у legacy

У `legacy/css/root.css` є `--gradient-light`, `--gradient-storm` і `--gradient-dawn`: це статичні лінійні градієнти. У `legacy/design-system.html` фон уже поєднував окремі `radial-gradient` для другорядного й третинного кольорів. У `legacy/MIGRATION-GUIDE.html` є `linear-gradient` від головного до другорядного. Готового модуля анімованого градієнта з Grain/Noise серед знайдених реалізацій немає.

## Висновок для work

- Використовувати **чинні семантичні ролі** `--pg-tone-main-base`, `--pg-tone-secondary-base`, `--pg-tone-tertiary-base`; це єдине джерело палітри для обох тем.
- Три незалежні кольорові плями на тлі градієнта з повільними рухами, різними траєкторіями й періодами. Рухати `transform`, не примушувати браузер постійно перебудовувати геометрію.
- Окремий злегка рухомий шум через вбудований `SVG feTurbulence` (жодних пакетів, canvas або мережевих ресурсів); декоративне SVG приховане від скринридера.
- Постійний контрастний текст завдяки окремим gradient-токенам для білого тексту й темної підкладки; не змінювати схвалену палітру інших компонентів.
- `prefers-reduced-motion: reduce`: зупинити рух плям і шуму, але зберегти статичний вигляд.
- Для прикладу на `/tools` використати **наявні** `createIconButton` та `showDialog`. Не створювати модальний менеджер і не перевизначати кнопки.

## Перевірка

Під час E2E перевірити: кнопка належить лише вкладці «Таблиці»; відкритий модальний Dialog містить `pinguin V6`; анімації активні в нормальному режимі та вимкнені в reduced motion; палітра бере чинні CSS-токени; Escape/закриття повертає фокус; вузький екран не має горизонтального переповнення.
