# Шапки таблиць Pinguin: legacy, ринкові підходи та рекомендація

Дата: 13 листопада 2026 року.

Це вихідне дослідження перед реалізацією. Актуальний реалізований контракт і межі перевірки наведено в [Collection View](../ui/collection-view.md#шапки-та-фільтри-колонок-2026-11-13). Згадки нижче про відсутні функції описують перевірений початковий знімок `work`.

## Висновок

У legacy підтверджено сортування кліком по заголовку та окремий фільтр, який відкривався при наведенні. Для нового інтерфейсу рекомендую поєднати стриману шапку за моделлю Google Material / IBM Carbon з доступом до фільтра колонки через наведення і явну кнопку.

Це дослідження коду та офіційної документації. Інтерфейс не змінено; поведінку legacy в браузері не перевірено. Порівняння описує конкретні перевірені рішення, без рейтингу часток ринку.

## Що знайдено у твоєму legacy

Перевірено гілку `legacy`, знімок `718aad5d7a1524cff7162061ead766f46f3985b5`.

| Дія | Підтверджена поведінка |
| --- | --- |
| Клік по заголовку | Сортування за зростанням; наступний клік — за спаданням; далі повторення двох станів. |
| Індикатор порядку | Стрілка вгору / вниз показується для активного сортування. У спокійному стані індикатор прихований CSS. |
| Наведення на колонку з фільтром | Через 400 мс відкривається панель фільтра. |
| Вміст панелі | Значення колонки, чекбокси, «Всі», кількість записів для кожного значення. Пошук з’являється, коли у списку понад 10 значень. |
| Зміна фільтра | Застосовується відразу після зміни чекбокса. |
| Перехід курсора на панель | Панель утримується відкритою. Відкладене закриття — 200 мс; перед видаленням передбачено ще 150 мс для приховування. |
| Розміщення панелі | Панель додається до `body`; використовується спільний `positionPanel()`. |
| Таблиця брендів | Фільтри увімкнено для «Країна» та «Статус». Сортування доступне також іншим відповідним колонкам. |
| Шапка при прокручуванні | `position: sticky; top: 0`. |

У прочитаному модулі hover-фільтра немає обробників клавіатурного відкриття, Escape, scroll або resize. Заголовки legacy створюються як `div` з обробкою кліку. Це конкретні прогалини перевірених модулів; повну доступність усієї старої сторінки окремо не тестовано.

## Що є у поточній таблиці

Перевірено `work`, знімок `747b6e7444d2797ec1dba8bd774b6d9462d1de36`.

У `collection-view` вже є нативна таблиця, кнопки сортування, `aria-sort` для активної колонки, спільний стан сортування для відображень даних та сортування до розбиття на сторінки. Поточний цикл кліків теж має два напрямки.

Нейтральний індикатор `swap-vert` створюється для неактивних колонок і залишається видимим. Це пояснює ряд однакових стрілок на наданому скриншоті. Вбудованої панелі фільтра конкретної колонки у прочитаному `collection-view` немає.

Джерела: [логіка collection-view](https://github.com/DSMykyta/pinguinV5/blob/747b6e7444d2797ec1dba8bd774b6d9462d1de36/src/ui/collection-view/collection-view.js#L150), [індикатори станів](https://github.com/DSMykyta/pinguinV5/blob/747b6e7444d2797ec1dba8bd774b6d9462d1de36/src/ui/collection-view/collection-view.js#L458), [стилі](https://github.com/DSMykyta/pinguinV5/blob/747b6e7444d2797ec1dba8bd774b6d9462d1de36/src/ui/collection-view/collection-view.css#L128).

## Що пропонують відомі системи

| Система | Перевірене рішення | Значення для Pinguin |
| --- | --- | --- |
| [Google Material, M2 Data tables](https://m2.material.io/develop/web/components/data-tables) | Іконка сортування може з’являтися при наведенні. Активний напрямок позначається стрілкою; клік по назві або стрілці змінює порядок. | Прибрати постійні нейтральні стрілки з усіх колонок; зберегти активну. Це офіційна документація M2. |
| [IBM Carbon](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) | Неактивні індикатори показуються при наведенні, активний залишається видимим. [Документація доступності](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/accessibility) також описує focus. | Найближча модель для чистої шапки та зрозумілого активного стану. |
| [Google Sheets](https://support.google.com/docs/answer/3540681?hl=en) | Сортування за алфавітом / числами; доступ до фільтрів кліком, пошук значень і вибір чекбоксами. | Добрий зразок вмісту панелі. Офіційна довідка не підтверджує автоматичне відкриття її наведенням. |
| [MUI TableSortLabel](https://mui.com/material-ui/api/table-sort-label/) | Окремий компонент із параметрами активного стану, напрямку та приховування індикатора. | Готовий архітектурний приклад компактного контролу. MUI — окремий проєкт; його документацію слід відрізняти від специфікацій Google. |
| [AG Grid](https://www.ag-grid.com/javascript-data-grid/column-menu/) | Меню колонки об’єднує додаткові операції. У режимі меню `legacy` кнопка може з’являтися на hover; це не означає автоматичного відкриття панелі. | Видимість кнопки та спосіб відкриття меню треба визначити окремо. |

Єдиного обов’язкового циклу сортування немає. [AG Grid](https://www.ag-grid.com/javascript-data-grid/row-sorting/) за замовчуванням використовує «зростання → спадання → скидання» і дозволяє змінити цикл. Для Pinguin рекомендую зберегти знайомі два напрямки, а «Скинути сортування» дати явною командою.

## Рекомендована поведінка для твого сайту

Наведене нижче — проєктна рекомендація на основі дослідження, а не готова реалізація чи дослівна вимога певної системи.

| Стан | Вигляд і реакція |
| --- | --- |
| Звичайна неактивна колонка | Назва без постійної стрілки. Місце під індикатор зарезервоване, ширина не змінюється. |
| Наведення або фокус | Легка підсвітка; з’являється індикатор доступного сортування. |
| Активне сортування | Стрілка напрямку залишається видимою після виходу курсора. |
| Клік по назві | Перший клік сортує; повторний змінює напрямок. |
| Колонка з фільтром | При наведенні / фокусі стає видимою окрема кнопка фільтра. Hover може відкривати панель через знайомі 400 мс. Кнопка відкриває її відразу. |
| Панель у роботі | Курсор можна перевести всередину. Після кліку або фокусування поля панель утримується для взаємодії. |
| Активний фільтр | Маркер фільтра видимий постійно, поруч доступне скидання. Напрямок сортування має окреме позначення. |
| Сенсорний екран | Кнопка фільтра видима; відкриття дотиком. |
| Закриття | Escape, клік зовні, скасування наведення до початку взаємодії. При скролі контейнера — закриття або коректне перепозиціонування за єдиним правилом сайту. |

Кнопка фільтра має власну область натискання: робота з нею не повинна випадково запускати сортування. Для тексту, чисел та дат потрібні зрозумілі назви напрямків: «А → Я», «Менші спочатку», «Новіші спочатку».

У панелі пропоную залишити значення з чекбоксами, кількість записів, пошук у довгому списку та команди скидання. Команди сортування можна додати зверху для явного вибору напрямку.

Клавіатурна взаємодія: нативна кнопка сортування, видимий focus, `aria-sort` на заголовку, кнопка відкриття панелі та повернення фокусу після Escape. [W3C APG](https://www.w3.org/WAI/ARIA/apg/patterns/table/examples/sortable-table/) показує кнопку на всю область заголовка. Для hover-панелі [W3C](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html) описує можливість закрити її, перевести всередину курсор та утримувати видимою під час взаємодії.

## Як зберегти модульність

Розширювати спільний `collection-view`, який уже відповідає за таблицю. Стан сортування має залишитися єдиним для шапки й інших засобів керування колекцією. Можливість фільтрації оголошувати в конфігурації колонки.

Панель колонки повинна використовувати наявні загальні засоби розміщення, фокусу й закриття. Для чекбоксів, поля пошуку та кнопок слід перевикористати компоненти сайту. Вибір між menu і popover залежить від наявної реалізації: панель із пошуком та чекбоксами потребує підтримки саме таких елементів і не повинна отримувати семантику простого меню механічно.

Для майбутньої реалізації перевірити: стабільність ширини шапки, обидва напрямки сортування, числові й датовані значення, фільтрацію до пагінації, збереження вибраних рядків, перехід курсора в панель, клавіатуру, touch та незалежність станів різних таблиць.
