# Rotating Placeholder — уточнення дослідження

## Фактична потреба (оновлено 2026-11-10)

Динамічні підказки мають автоматично відображати **попередні введення в тому самому типі поля**. Для сотень або тисяч інпутів користувач **не складатиме** масиви фраз у HTML. Якщо введень ще не було — в полі **нічого нового не показувати**. Увімкнення залишити локальним opt-in, не для всіх інпутів.

## Варіанти

- Нативний `placeholder` має одну строку і не підтримує анімовані переходи сам. У Pinguin необхідний невидимий для скринридера overlay, але він існує без видимого тексту, доки історія порожня.
- Приватні **підказки браузерного autocomplete** ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/autocomplete)) JavaScript не надаються. Натомість поточне `input.value` під час `change` можна додавати до власної ізольованої локальної історії. Залишаємо `autocomplete` без змін; не створюємо дублюючий dropdown.
- `<datalist>` ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/datalist)) потрібний для власних випадаючих списків і не вирішує автоматичний доступ до історії браузера. Не додаємо.
- У legacy «шарм» увімкнено декларативно через атрибут. Відтворюємо цей принцип, але не старий глобальний runtime чи сканування всього DOM на кожен рух.
- Погоджений shared `createInput` і `createFieldFrame` уже відповідають за input і його постійний label. Розширення — поведінка, не новий візуальний компонент.

## Остаточний opt-in

```html
<input name="product-feature" data-pg-rotating-placeholder>
```

`name` — автоматичний ключ історії. Опційно `data-pg-placeholder-history` перевизначає ключ; `data-pg-placeholder-interval` перевизначає затримку. JS еквівалент: `createInput({ label: 'Ознака товару', name: 'product-feature', rotatingPlaceholder: true })`. **Жодних масивів/рядків з прикладами**. Значення вперше з'являється після події `change`; для двох збережених фраз починається циклічний рух. Типи `email`, `tel`, `url`, `password` виключено, а opt-in дозволений лише для несекретних значень.

## Масштабування

Одноразове початкове відшукання opt-in полів допустиме. `MutationObserver` надалі збирає *лише* інпути в змінених DOM вузлах або з оновленими HTML-атрибутами; при кожному tick анімації не сканує всі поля. Життєві цикли, таймери та data source окремі за екземпляром.
