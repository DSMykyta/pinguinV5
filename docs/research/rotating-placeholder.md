# Rotating Placeholder — дослідження і реалізовані межі

## Задача власника

У Pinguin Next потрібна компактна поведінка, яка показує вже введені значення певного *типу* поля з вертикальною анімацією, **без ручних списків фраз для 1000 інпутів**. Активація — тільки `data-pg-rotating-placeholder` у HTML або `rotatingPlaceholder: true` у спільному `createInput`. Немає історії — немає додаткового вмісту.

## Порівняння браузерних можливостей

- **Browser autocomplete:** браузер сам показує власні приватні підказки; JavaScript не отримує список його збережених значень. Власна історія накопичується тільки після введення/підтвердження в поточному origin, не втрачаючи нативний autocomplete. [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/autocomplete).
- **Native placeholder:** статичний текст, не підтримує подвійний анімований шар. Потрібен декоративний `aria-hidden` текст, накладений над native input, без зміни його `value`. Статичний label за затвердженим [Field-контрактом](../ui/field.md) лишається зверху.
- **Datalist / Combobox:** відповідають за **вибір** значення, не за декоративну ротацію підказки. Pinguin уже має `createCombobox()`; не дублювати.
- **Legacy-шарми:** opt-in поведінка на елементі з явними mount/cleanup; не переносити глобальні MutationObserver, реєстри та повторні DOM-скани кожного кадру. [Попереднє дослідження](../legacy-behavior-research.md).
- **IntersectionObserver:** один observer для полів із реальною історією; припиняє роботу в невидимій області. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API).
- **Storage events:** інші вкладки цього origin отримують оновлення без опитування. [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event).

## Реалізована архітектура

`src/ui/input/placeholder-history.js` — provider без UI-залежностей. Обмеження даних: 12 останніх унікальних значень до 100 символів; storage exceptions, видалення окремого значення, очищення ключа, сповіщення змін. Дані зберігаються в локальному профілі браузера. Формат існуючих `pg:v1:input-placeholder-history:*` записів збережено для сумісності.

`src/ui/input/rotating-placeholder.js` — оркестратор опційної поведінки:
- один `IntersectionObserver` (коли підтримується), **один** `setTimeout` планувальника циклів для всіх видимих полів, **один** набір делегованих listeners;
- lazy: коли історії немає, у кожного opt-in поля існує лише запис у реєстрі, **без** overlay, DOM-обгортки або таймера;
- історія кешується за ключем, а сповіщення оновлюють тільки групу полів цього ключа;
- нормалізація числових індексів `products[0][feature]` → `products[][feature]`; необов'язкова область `data-pg-module`; явний ключ-перевизначення залишається;
- збереження на `change` за умовчанням, з перевіркою native validity; для форми можливе `data-pg-placeholder-save="submit"`. Повністю підтверджене збереження на сервері потребує callback від власника feature після успішної операції;
- пауза при hover, focus (із прихованою підказкою), згорнутій вкладці, системному reduced motion та через API для налаштувань; transition трансформує лише текст протягом 840 мс, не геометрію input;
- додавання/видалення HTML і перенесення поля між `data-pg-module` не змінює інші features, при destroy повертається native DOM.

## Що свідомо не вводимо

- Жодної окремої FAB, popup чи Combobox; жодних нових npm-пакетів або невидимих глобальних `window.*` API.
- Не імпортуємо історію з браузера, іншого пристрою чи акаунта.
- Не встановлюємо довільний строк життя історії без погодженої політики зберігання; є ручні API видалення. Власник може змінити data provider без переписування анімації.
- UI-кнопку зупинки не вставляємо в Shell без запиту; для дотримання вимог доступності в реальному використанні автоматично рухомого контенту можливість виклику `setRotatingPlaceholdersPaused` слід підключити до **існуючих** налаштувань доступності.
- Не оголошуємо 1000 полів «продуктивними за вимірюваннями» без Chrome performance профілювання. E2E перевіряє lazy DOM; реальний замір FPS, CPU і пам'яті — окрема перевірка.

Дійсний API та критерії: [docs/ui/rotating-placeholder.md](../ui/rotating-placeholder.md).
