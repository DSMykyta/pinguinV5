# Rotating Placeholder — коротке дослідження

## Вихідна задача

У полях товару потрібно необов'язково анімувати `Sugar Free → Time Release → …`, з виходом старого слова вниз і входом нового зверху, та використовувати введені користувачем значення. Користувач має вмикати це **безпосередньо в HTML**, а не для всіх полів.

## Порівняння

- **Нативний `placeholder`** — одна строка: браузер не дає інтерфейсу для анімації кількох незалежних рядків. Використовуємо доступний нативний `<input>` + неінтерактивний текстовий overlay.
- **`autocomplete` браузера** ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/autocomplete)): браузер сам вирішує, які власні збережені пропозиції показати. JavaScript може прочитати вибране значення через `input.value`, але не перелік прихованих історичних підказок. Нативний `autocomplete` не відключаємо; opt-in `localStorage` зберігає лише значення, введені/підтверджені **після** встановлення механізму.
- **`<datalist>`** ([MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/datalist)): можливий власний dropdown, але відрізняється між браузерами та взаємодіє з нативними підказками. Не додаємо без окремого запиту, особливо оскільки є спільний `Combobox`.
- **Legacy шарми** ([наявне дослідження](../legacy-behavior-research.md)): поведінка вибирається HTML-атрибутом, має локальний життєвий цикл та cleanup; старий глобальний runtime не переносимо.
- **Поточний Next**: `createInput` керує реальним input, `createFieldFrame` дає постійну геометрію і підпис. Розширюємо їхню композицію opt-in поведінкою. Ніяких нових Input, label, анімацій Shell чи імпортів feature → feature.

## Прийнятий контракт

`data-pg-rotating-placeholder` є opt-in; `data-pg-placeholder-history` дозволяє локальне збереження тільки несекретної інформації. Окремі екземпляри мають власні таймери й DOM; історія лише за явним ключем. Мінімальний CSS із наявними семантичними токенами. Анімація рухає тільки текст, не геометрію input. Reduced motion та скринридери не отримують нескінченного живого повідомлення.
