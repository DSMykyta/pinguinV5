# Rich Text Editor — режими «Редактор» та «HTML»

**Статус:** реалізація в `work`, 2026-11-09. [Дослідження](../research/rich-text-editor.md). Окремий `src/ui/textarea` залишається для plain-text полів.

## Суть

Одна робоча область, **два взаємовиключні режими**, а не дві паралельні колонки. **«Редактор»** — WYSIWYG `contenteditable` із панеллю форматування (жирний, курсив, підкреслення, абзац, H1–H3, списки, цитата); **«HTML»** — повноцінно редагована `textarea` з вихідним HTML цього документа. Кнопки «Редактор / HTML» перемикають режим без відкриття іншого вікна. Редагування HTML не перемальовується на кожну клавішу: чернетка зберігає курсор і рідний undo. Повернення до візуального режиму застосовує санітизований код; експорт у будь-якому режимі очищує HTML.

## API

`createRichTextEditor({ content?, editable?, toolbar?, code?, stats?, label?, onChange?, onModeChange? })` повертає **непідключений** екземпляр:

`{ element, input, source, getMode(), setMode('editor'|'html'), getHTML(), getText(), getSource(), setHTML(html), setEditable(boolean), focus(), execute(command), clear(), destroy() }`.

- `code: true` за замовчуванням; `code: false` прибирає перемикач та HTML-режим, якщо потрібне звичайне поле rich text.
- `toolbar` і `stats` не залежать від режимного перемикача; `toolbar: false` не вимикає можливість вибрати HTML.
- `onChange({ html, text, mode })` — зміна змісту; `onModeChange(mode)` — завершене перемикання. Компонент не зберігає даних у сховище.
- `getSource()` у HTML-режимі повертає **сирий код чернетки**, `getHTML()` — **очищений HTML**. Якщо код містить недопустимі теги/атрибути, під час переходу в редактор вони видаляються з повідомленням.
- `setEditable(false)` встановлює `contenteditable="false"` і `textarea.readOnly`; перемикання режимів доступне для перегляду.
- Історія `undo/redo` в WYSIWYG локальна; у HTML-режимі працює нативний undo/redo браузерної `textarea`. Вихід із HTML створює запис у WYSIWYG history, тож зміна з коду може бути скасована після повернення.

## Структура / LEGO

- `rich-text-editor.js` — композиція та єдине джерело режиму, публічне API й очищення ресурсів.
- `mode.js` — незалежний сегментований перемикач, знає лише `getMode`, `setMode`, `subscribe`.
- `toolbar.js` — кнопки форматування, автоматично вимикаються у HTML-режимі.
- `commands.js` — обмежені `Selection`/`Range` команди, без deprecated `execCommand`.
- `history.js` — історія візуального редагування.
- `html.js` — дозволені HTML-теги/атрибути та безпечний імпорт/експорт (не використовує сторонніх npm пакетів).
- `stats.js` — незалежна статистика тексту в обох режимах.
- `rich-text-editor.css` — лише вигляд власного компонента та спільні токени `--pg-*`.
- `src/features/tools/rich-text-editor-demo.js` — приклад у вкладці `/tools` → «Текст». Shell та інші UI не імпортують редактор.

## Обмеження

Native editing — це контрольований старт, не повноцінна заміна ProseMirror: підтримка багатоблочних selections, складної вкладеної HTML-розмітки, IME, undo в усіх браузерах та імпорту Word має додаткові ризики. Сторонній HTML очищується суворим allowlist; CSS, скрипти, iframe, зображення та непідтримувані атрибути не переносяться між режимами. Окреме серверне очищення **обов'язкове** для зберігання й публікації. Автозбереження, пошук/заміна та перевірка слів — майбутні незалежні «шарми», не частина поточного ядра.

## Перевірка

`node --test src/ui/rich-text-editor/*.test.js`, `npm run check`, `npm run test:e2e`. Браузерні сценарії мають покрити: введення у WYSIWYG → HTML, редагування коду → рендер, спробу XSS, undo після повернення, source-native undo, роздільність екземплярів, disabled, клавіатуру, мобільну ширину.
