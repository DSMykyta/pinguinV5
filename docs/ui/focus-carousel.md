# Focus Carousel — фокусна карусель

## Дослідження
Референс власника: Code with Ania Kubow, десять кадрів відео. Картка 60% ширини, 3:4, scroll-snap-align: center, scroll-snap-type: x mandatory, animation-timeline: view(inline). На краях scale .85, opacity .7; у центральній зоні 30–70% scale 1, opacity 1. Повний keyframes не видно, тому .7 та симетричне плато — реконструкція з останніх кадрів, а не дослівна копія.
- [Chrome: Carousel Slide Effects](https://developer.chrome.com/docs/modern-web-guidance/guides/ui-atoms/carousel-slide-effects) — масштаб від позиції, native CSS за підтримки.
- [MDN: view()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-timeline/view) — прогрес видимості відносно найближчого scrollport.
- [MDN: scroll-snap-align](https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-snap-align) — центр snap target.
- [Material 3 Carousel](https://m3.material.io/components/carousel/overview) — hero centered як візуальний орієнтир. Повна M3 keyline/mask геометрія не є ціллю цього ефекту.

Перевірено реєстр work, Section Navigator та дерево legacy (за назвами carousel/slider/scroll-snap знайдено лише forms/slider.css). Section Navigator реагує на вертикальну межу й перемикає секції, Focus Carousel має один горизонтальний scrollport і безперервне положення карток. Не дублює існуючу поведінку. Повний пошук вмісту legacy не виконано.

## Контракт
`createFocusCarousel({ items, label, autoplay, autoplayInterval }) → { element, goTo(index, { behavior }), setAutoplay(enabled), destroy() }`. items — масив DOM-вузлів; власник передає готовий вміст. Немає бізнес-даних, Shell, FAB, нового пакета або примусового автоматичного гортання. Перший/останній елементи центруються за допомогою симетричних flex-spacer. Внутрішній surface анімується, зовнішній snap target зберігає layout. Іменована view timeline на кожному target є еквівалентом view(inline) на його поверхні без зміни геометрії snap target.

Native: CSS view timeline, scale/opacity, 0–30–70–100%. Fallback: один кадр на scroll/resize, вимір незмінних target і та сама формула; без постійного циклу. Reduced motion: повний розмір і непрозорість, програмне гортання без анімації. Нативний touch і trackpad; миша — локальний drag після порогу 6px, snap відновлюється при завершенні; інтерактивний вміст не перехоплюється. Фокус scrollport, стрілки, Home/End. Вертикальне колесо на каруселі перемикає картки; на краях повертає прокрутку сторінці. Destroy знімає слухачі, ResizeObserver та кадр. Демо використовує справжні фотографії Unsplash, перше фото спільне за джерелом з Image Field; інші — чотири окремі пейзажі. Демо у /tools → Ефекти.

## Плавне завершення, колесо й автопрокрутка
За [MDN scroll-snap-type](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scroll-snap-type) зміна snap properties може викликати повторне прив’язування. Стан settling тримає snap вимкненим до точного центру, рух від поточної позиції — один скінченний RAF, spatial normal duration, cubic ease-out. Переривання мишею зберігає поточну позицію; reduced motion завершує одразу. Wheel: вертикальна серія подій — одна картка, 180 ms межа серії, горизонтальний трекпад нативний, модифікатори не перехоплюються. На кінцях вертикальне колесо віддається сторінці. Autoplay: opt-in, 3500 ms, рух вперед-назад без стрибка через усі картки; пауза при hover, фокусі, взаємодії, поза видимою областю, прихованій вкладці та reduced motion. Switch — наявний глобальний UI. [WAI carousel](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/). Зовнішні фото потребують мережі; нейтральний фон і alt при помилці. Таймер і observer очищаються при destroy.
