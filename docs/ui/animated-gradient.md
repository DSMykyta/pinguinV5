# Animated Gradient — безшовне поле живого кольору

**Компонент:** `src/ui/animated-gradient`. **Гілка:** `work`. **Оновлено:** 2026-11-13.

## Контракт

- Публічний API без змін: `createAnimatedGradient({text = 'pinguin V6'})` повертає автономний `HTMLElement`. Діалог та Shell є споживачами, але компонент від них не залежить.
- **Тільки колір:** жодних смуг, намальованих геометричних країв плям, `border-radius` на кольорових шарах, `clip-path`, `filter:blur()` чи зернистості. Немає SVG filter і сторонніх бібліотек.
- Фон — суцільна **рівновагова суміш** `main`, `secondary`, `tertiary` (по 33⅓% компонентного базового кольору). Це визначення базового змішування, **не** обіцянка 33⅓% пікселів кожного hue у рухомому кадрі.
- Шість незалежних безконтурних `radial-gradient`-полів: **по два для кожного семантичного кольору**. Кожне поле однакового розміру (115% ширини, 160% висоти), з дуже широким плавним падінням інтенсивності до прозорості; їхні центри розкидані по двох осях, без лівої/правої колірної колонізації.
- Повільний рух здійснюють тільки CSS `transform: translate3d/scale` у двох повторно використовуваних траєкторіях (`a`, `b`) зі своїм періодом і фазою для кожного поля. **Жодної анімації `background-position`, `filter` або CSS layout.**
- Палітра використовує наявні `--pg-tone-main-base`, `--pg-tone-secondary-base`, `--pg-tone-tertiary-base` світлої й темної тем. Самі semantic tones тут не перевизначаються. Через те, що `main` та `secondary` у чинній темі обидва сині, колірна *гама* може лишатися синішою попри рівну вагу ролей.
- Білий напис `pinguin V6` залишається нерухомим, єдина тінь напису — `--pg-color-gradient-title-shadow`. Псевдошару із затемненням у вигляді окремої плями немає.
- `prefers-reduced-motion` зупиняє рух; усі шість кольорів залишаються видимими. Коли `showModal()` відкритий, фон позаду паузиться чинним Dialog, а активний градієнт усередині Dialog продовжує рух.

## Відповідальність

`src/ui/animated-gradient/animated-gradient.js` створює тільки шість декоративних `span[aria-hidden=true]` та текст; `src/ui/animated-gradient/animated-gradient.css` володіє кольоровими полями та їхнім рухом, усі значення кольорів зберігаються в `src/styles/tokens.css`. Нічого не додаємо у feature CSS або глобальні кнопки.
