# Animated Gradient — спільний фоновий ефект

**Призначення:** автономна поверхня з плавно анімованим трикольоровим градієнтом і делікатною зернистістю. Дослідження `legacy`: [animated-gradient](../research/animated-gradient.md).

## Контракт

- `src/ui/animated-gradient/animated-gradient.js` експортує `createAnimatedGradient({ text = 'pinguin V6' })`, що повертає автономний `HTMLElement`. Функція не відкриває модалку, не читає вкладки й не залежить від Shell.
- `src/ui/animated-gradient/animated-gradient.css` володіє тільки `.pg-animated-gradient` та його дочірніми елементами. Кольори визначаються семантичними `--pg-tone-main-base`, `--pg-tone-secondary-base`, `--pg-tone-tertiary-base`, додаткові кольори читабельності — лише `src/styles/tokens.css`.
- Кольорові плями рухаються незалежно; SVG-шум має власний легкий рух; текст — нерухомий. Ефект не використовує сторонніх бібліотек і сторонніх файлів.
- При `prefers-reduced-motion` всі декоративні анімації вимкнені. Декоративні шари мають `aria-hidden`.
- `src/features/tools/animated-gradient-demo.js` — **лише сценарій**: кнопка у вкладці «Таблиці», яка викликає спільний `showDialog` з `createAnimatedGradient` та великим білим текстом `pinguin V6`.
- Зовнішні кнопки, заголовок, закриття й фокус належать чинному `src/ui/dialog`; жодного другого Dialog, спеціального page fill чи змін Shell.

## Приймання

1. Натискання тестової кнопки відкриває справжній Dialog; Escape, кнопка закриття та підтвердження закривають його з поверненням фокуса.
2. Білий `pinguin V6` по центру, фон із трьох наявних ролей кольору; рух плям помітний, зернистість делікатна.
3. Light/dark автоматично підхоплюють відповідні три токени. Без scroll-jump, без кнопок і CSS-оболонок-дублікатів.
4. Mobile, reduced motion, відсутність зайвих npm-залежностей. Тест: `tests/e2e/animated-gradient.spec.js`.
5. Статус реалізації та браузерних перевірок вказувати окремо; коміт не підтверджує локальну роботу сам собою.
