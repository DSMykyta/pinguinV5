# Animated Gradient — незалежний рух двох кольорових полів

**Гілка:** `work`. **Оновлено:** 2026-11-13. **Референси:** наданий користувачем відеоприклад із CSS radial gradients; візуальні роботи Suno ([Metalab](https://www.metalab.com/work/suno), [60fps.design](https://60fps.design/shots/suno-create-song-popup-background-animation)). Публічні роботи Suno **не підтверджують точний CSS-код**, лише характер м'яких кольорових хвиль.

## API та повторне використання

```js
const gradient = createAnimatedGradient({
  text: 'pinguinV6', // null для фону без напису
  preset: 'light',  // light | storm | dawn
});
gradient.getPreset();
gradient.setPreset('storm');
```

Наявний `createAnimatedGradient` не залежить від Dialog, ButtonGroup чи Sparkles. Демонстраційний адаптер `src/features/tools/animated-gradient-demo.js` використовує вже наявні `createButtonGroup`, `createSwitch`, `createSparkles` і `showDialog({ presentation:'edge-to-edge' })`.

**Сумісні внутрішні ключі** `light/storm/dawn` збережені; це назви рухів, а не legacy-кольорові рецепти. Початковим режимом є `light` («Переміщення»), щоб рух був видимим одразу.

## Чому попередній варіант здавався нерухомим

До 13.11.2026 два `radial-gradient` перебували на **одному** `::before`. Його transform змінював положення обох плям одночасно, тому вони майже не переміщувалися одна відносно одної. Навіть три різні `@keyframes` не давали двох незалежних траєкторій.

**Нова конструкція:** базовий `background: var(--pg-tone-main-base)`, `::before` — тільки `secondary`, `::after` — тільки `tertiary`. Кожен псевдоелемент має власні `transform` keyframes та власну тривалість. Ніякого додаткового HTML, Canvas, WebGL, JS-ticker або альтернативного компонента.

- **Підкладка:** кожен шар має `inset:-50%`, тобто займає **200% ширини й 200% висоти** контейнера. Колір згасає до прозорості всередині шару; жодного видимого прямокутного краю.
- **М'які переходи:** кілька RGBA-стопів одного `radial-gradient` із `color-mix()`. Не використовуємо `filter:blur()` на великих шарах, щоб не навантажувати GPU зайвим фільтром.
- **Тема:** кольори строго з `--pg-tone-main-base`, `--pg-tone-secondary-base`, `--pg-tone-tertiary-base`. Усе автоматично оновлюється при зміні теми.
- **Напис:** `pinguinV6` над обома шарами. Іскри залишаються окремим, необов'язковим компонентом; анімаційний шум не додається.

## Режими: одна база, дві незалежні траєкторії

| Кнопка | Ключ | Secondary | Tertiary |
| --- | --- | --- | --- |
| **Переміщення** | `light` | Проходить різними ділянками площини за 8 с | Рухається іншим маршрутом за 10,5 с |
| **Обертання** | `storm` | Описує коло за 9 с | Обертається у зворотний бік за 12 с |
| **Пульсація** | `dawn` | Змінює розмір/прозорість і переміщується за 5,2 с | Пульсує не синхронно за 6,7 с |

Траєкторії замкнені (`0% = 100%` або `0° = 360°`) для безшовного повтору. Немає `alternate` із зупинкою руху на кожному кінці, а швидкість лінійних переміщень не сповільнюється на кожній контрольній точці.

## Продуктивність та доступність

Анімуються **тільки `transform`** у двох режимах; «Пульсація» додатково використовує `opacity`. Розмір підкладки й пам'ять compositor збільшилися порівняно зі старим 140%-шаром, але кадри не малюються JS, немає `background-position` анімацій і фільтрів blur на величезній текстурі. Реальні GPU/FPS на ПК користувача потребують окремого профілю.

- `prefers-reduced-motion`: обидві анімації зупинені; палітра лишається видимою.
- Коли відкритий Dialog, існуючі правила паузять фон позаду, але обидва градієнти **всередині** активного Dialog продовжують рух.
- Три кнопки й опційні іскри працюють як раніше; код Sparkles не змінювався.

## Перевірки

`tests/e2e/animated-gradient.spec.js` перевіряє два незалежні radial gradients, збільшений запас, зміну transform в часі, різні режими, reduced-motion, modal pause/return, відсутність Canvas/noise.

**Візуальна локальна проба:** ізольований Chromium (три режими, ~440×420), кадри з інтервалом 1,8 с. У тесті понад 92% вибірково перевірених пікселів **кожного** режиму змінили RGB більше ніж на 15 одиниць хоча б в одному каналі. Це підтверджує помітність переміщення на еталонній пробі, але не означає проходження повного E2E/production build.

## Окремий Suno-подібний CloudGradient

На нову пряму вимогу додано [CloudGradient](cloud-gradient.md) — глобальний WebGL renderer одного semantic tone. Існуючий AnimatedGradient залишається CSS-ефектом з двома окремими рухомими псевдошарами, з тим самим API й режимами. [Дослідження Suno](../research/suno-canvas-gradient.md).
