# Думання — Thinking Progress

Тонкий безперервний індикатор обробки без визначеного відсотка. Демо розміщене у `/tools` → «Таблиці», після хвилястого прогресу.

## Поведінка

- Висота 4px через `--pg-thinking-progress-height`, повна ширина контейнера.
- Кольори — наявні `--pg-tone-main-base`, `--pg-tone-secondary-base`, `--pg-tone-tertiary-base` активної теми, як у спільному Animated Gradient.
- Повторюваний градієнт плавно рухається з постійною швидкістю; початок і кінець циклу збігаються. Нерухома alpha-маска пом’якшує крайні 15% смужки.
- `prefers-reduced-motion` залишає нерухомий градієнт. У forced colors лишається видима системна лінія.
- `role="progressbar"`, доступна назва; `aria-valuenow` відсутній, оскільки відсоток невідомий. Власник асинхронної операції керує `aria-busy` своєї області.

## API й межі

`createThinkingProgress({ label = 'Думання' })` повертає `{ element, destroy() }`. Непорожній текстовий `label` обов’язковий. Власник додає `element` у свій контейнер і викликає `destroy()` після завершення операції.

`src/ui/thinking-progress` володіє тільки індикатором. Жодних таймерів, підписів, відсоткової моделі, кнопок, прив’язки до Shell або імпортів feature. CSS завантажує `src/main.js`. Демо відповідає тільки за заголовок, опис та розташування. Загальне призупинення фонових CSS-анімацій під модальним Dialog діє без окремих підписок.

## Приймання

Перевірити справжню вкладку, доступну назву, відсутність фальшивого відсотка, геометрію й рух без розриву циклу, палітру обох тем, mobile та pinned aside, reduced motion, forced colors, незалежність інстанцій і cleanup. Наявний Wave Progress залишається поруч.
