# Wave Progress — спільний індикатор завантаження

**Контракт 2026-11-13.** Джерело: шість наданих скриншотів і [аналіз CSS Mask](../research/wave-progress.md).

## API

`createWaveProgress({ value = null, label = 'Завантаження' })` → `{ element, setValue(value), getValue(), destroy() }`.

- `value` — число від 0 до 100 включно; дробові значення дозволені. `null` — невизначений прогрес без вигаданих відсотків. Некоректні значення відхиляються; мінімум/максимум нормалізуються у діапазон.
- `setValue(value)` змінює тільки візуальну ширину хвилі та ARIA-стан. Компонент не прив'язаний до задач, кнопок, таблиць, таймерів або маршруту.
- `element` має `role="progressbar"`, доступну назву та `aria-valuemin="0"`, `aria-valuemax="100"`. `aria-valuenow` існує тільки коли число відоме. Зовнішня розмітка може показувати відсоток текстом.
- `destroy()` видаляє лише власний DOM-вузол, ніяких глобальних обробників/таймерів немає.

## Стиль і механіка

- `src/ui/wave-progress/wave-progress.js` — незалежна поведінка; `wave-progress.css` — єдиний власник геометрії, маски й анімації `.pg-wave-progress*`.
- Висота хвилі 10 px; період маски 20 px, 4 px stroke, кутова крива `M0 5 Q5 0 10 5 T20 5`. Зсув `mask-position: 0→20px` лінійний за 0.6s; повний цикл стикується без стрибка.
- Відступ активної хвилі від пасивної доріжки 4 px; остання 4 px заввишки, з правою крапкою 4 px.
- Ширина активної хвилі визначається `--pg-wave-progress-width` (лише від `setValue`), а не власним таймером.
- У `indeterminate` режимі хвиля змінює ширину без числової претензії на прогрес; активний mask-малюнок продовжує течію.
- Мобільна ширина, light/dark і `prefers-reduced-motion`; fallback у forced-colors. Не змінювати стиль спільних Button, Slider, Shell, Toast, Dialog.
- Немає окремого SVG DOM або залежностей; повторюване зображення використовується як маска з CSS data URL.

## Демо та тести

- `src/features/tools/wave-progress-demo.js` демонструє у вкладці **«Таблиці»** визначений прогрес 61%, ручний повзунок через спільний `createSlider`, кнопку запуску **імітації** та окремий невизначений режим.
- `src/features/tools/wave-progress-demo.css` задає тільки композиційні відступи демо; зовнішня кнопка оформлюється чинним `pg-button`.
- `tests/e2e/wave-progress.spec.js`: вкладка, зміна 61→0→100, числовий ARIA-стан, безшовна 20px маска, indeterminate, reduced-motion, cleanup, mobile.
- Перед твердженням про готовність виконати `npm run check` і релевантний Playwright E2E; збірка не дорівнює браузерній перевірці.

## Вирівнювання із Slider (оновлення 2026-11-13)

Обидва компоненти використовують `--pg-color-progress-active` та `--pg-color-progress-inactive` у світлій і темній темах. Геометрія Wave: період 20px через `--pg-wave-period`, висота хвилі 10px через `--pg-wave-height`, доріжка/крапка/проміжок 4px через окремі alias-токени, частота руху через motion-токен. У CSS компонента числові значення довжин замінені на `var(...)`, крім безрозмірних координат path всередині SVG data URI. Спільну 32px висоту Checkbox/Mini використовує ручка **Slider**; сам Wave має залишатися тонким індикатором. [Аудит розмірів](../research/slider-wave-size-audit.md).
