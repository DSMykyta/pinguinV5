# Photo Charm — атмосферне тло з фотографії

## Призначення

Опційний візуальний «шарм»: оригінальне фото чітке зверху, під ним — **те саме** зображення в тій самій геометрії, насичене й розмите, із рівномірним зниканням з усіх чотирьох боків. Збережено `blur(40px) saturate(1.8)`, прибрано масштаб `1.1` і еліптичну маску. Прозорий padding розмитого шару збігається з padding компонента (32px, на вузькому екрані 24px). Дві лінійні alpha-маски з `mask-composite: intersect` плавно гасять ефект до нуля на зовнішніх межах, включно з кутами. CSS застосовує filter до mask: [MDN CSS Masking](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Masking). Canvas, WebGL і додаткові пакети не потрібні.

## Попередні механізми

- У `legacy` поведінки-шарми монтувалися окремо; готового image ambient glow немає. `image-show` — це збільшений preview на hover, його не змінюємо.
- У Next вже є `createImageField` для вибору файла та URL lifecycle і `createSwitch` для порівняння станів. Обидва перевикористовуються в демонстрації.
- Фото не копіюється у Canvas і не проходить перетворень. Дві HTML `img` використовують той самий `src`, а браузер кешує отримані дані. Розмитий шар позначено `aria-hidden`, основний має `alt`.

## Публічний API

```js
import { createPhotoCharm } from '../../ui/photo-charm/photo-charm.js';

const charm=createPhotoCharm({src:'/photo.jpg',alt:'Пейзаж',enabled:true});
host.append(charm.element);
charm.setSrc('/next.jpg','Інше фото');
charm.setEnabled(false);
charm.destroy();
```

Використовувати лише зі шляхом до зображення/підготовленим URL; передавати src як **DOM-властивість**, а не конкатенувати HTML чи CSS. Компонент не завантажує файли, не створює і не відкликає `blob:` URL: власник `ImageField` відповідає за їхній життєвий цикл. Після `destroy()` методи зміни стану недоступні.

CSS-параметри для власника: `--pg-photo-charm-ratio` (типово `3 / 2`), `--pg-photo-charm-blur` (40px), `--pg-photo-charm-saturation` (1.8). Стилі і маска належать тільки `src/ui/photo-charm`. Рамка, backdrop і шари Shell не змінюються.

## Інтеграція

`/tools` → **Елементи** → **Зображення**. У тому самому блоці розміщені preview з шармом, спільний `Switch` і чинний `ImageField`: вибір локального фото змінює обидва шари, видалення повертає демонстраційний приклад. Якщо зовнішній приклад недоступний, застосовується локальний SVG-плейсхолдер; завантажене користувачем фото в мережу не передається. Нову вкладку, FAB або режим Main не створено.

## Критерії приймання

1. Однаковий URL чіткого і розмитого шарів; декоративний шар приховано від assistive technologies.
2. Вимкнення прибирає лише атмосферне тло, а не фото; перемикач доступний із клавіатури.
3. Після вибору файла відбиток оновлюється. Відкликання object URL лишається відповідальністю `ImageField`.
4. Вузький екран, світла й темна теми: візуальний ефект не змінює геометрії Shell; `prefers-reduced-motion` вимикає transition.
5. Однакова ширина згасання з усіх боків, відсутність видимого прямокутного зрізу навіть у контейнері з overflow:hidden; розмиття не змінює основне фото.
6. Кілька екземплярів не мають спільного стану; `destroy()` видаляє лише власні DOM-вузли.
