# Pinguin Next — глобальна навігація і маршрути

**Обов'язковий принцип:** компонування навігації задає Shell один раз для всіх сторінок. Жоден інструмент не створює власну шапку, sidebar чи пошук.

## Глобальна схема

| Зона | Власник | Поведінка |
|---|---|---|
| Лівий sidebar | `src/shell/sidebar/` | Показує лише справжні зареєстровані сторінки |
| Під активним пунктом меню | `sidebar.localNavigation` + `src/ui/tabs/` | Вкладки й режими поточної сторінки; один глобальний слот, а не окремий центрований toolbar |
| Верхня шапка, зліва | `src/shell/shell.js`, `src/shell/page-outlet.js` | «Інструменти · Таблиці/Текст», той самий елемент для всіх маршрутів |
| Верхня шапка, справа | `src/shell/search/` і кнопка aside | Працюючий пошук поряд з контекстною кнопкою, без порожніх декоративних дій |
| Правий aside | `src/shell/aside/` | За замовчуванням popover, за бажанням — закріплений; має власний контекст активної вкладки |
| Нижній лівий кут | `src/shell/sidebar/` | Теми light → dark → system, як у legacy |

Це одна схема для будь-якої сторінки: `tool`, `collection`, `record`, `settings`. Тип впливає на вміст, але **не** на глобальне компонування.

## Маршрути

- `src/app/page-registry.js` — єдиний реєстр; реєструємо лише наявні функціональні сторінки.
- `src/app/router.js` — URL і браузерна історія. `/` без окремої сторінки перенаправляється на `/tools` через `replaceState`.
- Сторінку «Огляд», її файли та тип `overview` прибрано. Нову порожню стартову сторінку не створювати.
- `src/shell/page-outlet.js` монтує модуль, передає `AbortSignal`, очищує попередній модуль, підставляє глобальні вкладки, контекст aside та пошукові елементи.
- Невідома адреса показує повідомлення з робочим посиланням на `/tools`.

## Спільні вкладки

- Кожна сторінка передає у `src/ui/tabs/tabs.js` масив вкладок. Компонент відповідає за їхній ARIA-стан, клавіатурні стрілки та cleanup.
- `sidebar.localNavigation` фізично розташовується **одразу після активного посилання**, а не в header. При переході на іншу сторінку слот пересувається за новим активним пунктом.
- Звичайний режим — малі круглі іконки та м'яка капсула активної вкладки, що плавно розгортається вправо за принципом `legacy`.
- У згорнутому sidebar `@container pg-local-nav` адаптує ті самі кнопки до вертикального компактного ряду іконок. На мобільному sidebar широкий — вкладки знову горизонтальні.
- `src/ui/tabs/tabs.css` оформлює тільки сам компонент. `src/shell/sidebar/sidebar.css` оформлює тільки місце його монтування. Взаємних BEM-селекторів у цих файлах немає.

## Глобальний пошук

- `src/shell/search/search.js` і `search.css` володіють кнопкою пошуку, полем, результатами, клавіатурою та закриттям.
- Shell додає зареєстровані сторінки до індексу. Активний модуль передає додаткові пошукові дії через `setSearchEntries(entries)` із `mount(host, context)`.
- Пошук серед доступних пунктів реально працює: зараз можна знайти вкладки «Таблиці» і «Текст» та переключитися на них.
- Кнопка стоїть **поруч із правою кнопкою aside** у спільній шапці; `Ctrl/Cmd+K` відкриває пошук, Escape закриває його. Немає потреби дублювати пошук на кожній сторінці.
- Поки немає справжнього контентного індексу, не імітувати пошук усередині товарів чи документів.

## Маніфест сторінки

```js
export const manifest = {
  id: 'table-generator',
  title: 'Таблиці',
  route: '/table-generator',
  type: 'tool',
  navigation: { icon: 'table-2', order: 10 },
  load: () => import('./index.js'),
};
```

Це приклад майбутнього інструмента, не готовий маршрут. Наразі активний лише `/tools`.

## Автоматичні перевірки

`tests/e2e/navigation.spec.js` — перенаправлення з `/`, відсутність «Огляду», пошук, адаптивність.

`tests/e2e/tools.spec.js` — вкладки саме під пунктом меню, перемикання, компактна навігація, контекст aside.

`tests/e2e/page-layout.spec.js` — єдина геометрія заголовків і шапки.

`tests/e2e/shell.spec.js` — чотири кути, теми, зміни ширини та мобільна поведінка.
