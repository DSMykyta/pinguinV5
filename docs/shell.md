# Pinguin Shell — етап 01

Перший виконаний шар Pinguin Next. **Це оболонка**, не реалізація генератора таблиць.

## Підтверджена структура

- `src/shell/shell.js` — життєвий цикл, оркестрація й стан відкритих панелей.
- `src/shell/sidebar/sidebar.js` — основна навігація. Тільки реально доступний «Огляд»; невиконані модулі не показуються як кнопки.
- `src/shell/aside/aside.js` — контекстна панель. Наразі перемикач системної/світлої/темної теми; у майбутньому її наповнює активний модуль.
- `src/shell/overview/overview.js` — читабельна інформація про послідовність роботи; не є симуляцією інструмента.
- `src/ui/button`, `src/ui/icon`, `src/ui/data-row` — спільні візуальні примітиви.
- `src/core/preferences.js` — безпечне локальне зберігання уподобань (версійний ключ `pg:v1:shell:preferences`).
- `src/styles/tokens.css` — єдині кольори, розміри та теми; в CSS компонентів немає кольорових літералів.

## Реальна поведінка

1. Згортання/розгортання лівої панелі на широких екранах; збереження вибору.
2. Контекстна панель відкривається/закривається; стан desktop зберігається.
3. Вибір «Системна», «Світла», «Темна» миттєво оновлює інтерфейс та зберігається.
4. На вузьких екранах ліва й права панелі працюють як окремі шторки. Натискання на затемнений фон або Escape закриває їх.
5. Є підписи та ARIA для керування, focus-visible і reduced-motion.
6. Відсутність доступу до localStorage не блокує роботу інтерфейсу.
7. HMR очищує глобальні слухачі під час розмонтування оболонки.

## Не входить до цього етапу

- Генератор таблиць, редактори, API, авторизація, маршрути майбутніх модулів, меню рядків та пошук.
- Відновлення старих інструментів.
- Повний реєстр модулів (з'явиться з першим робочим модулем; поки не створюємо зайву абстракцію).
- Гарантія візуальної/мобільної якості без перевірки у Preview.

## Ручна перевірка Preview

- Desktop 1440px: згорнути sidebar, закрити aside; перевірити відступи та невтрату вмісту.
- 1024px, 768px, 390px: відкрити обидві шторки окремо; перевірити Escape, backdrop, фокус.
- Перемкнути всі три теми; перезавантажити сторінку і перевірити збереження.
- Клавіатура: Tab, Enter, Space, Escape; focus-visible на кнопках і radio.
- Системна тема на пристрої зі світлим і темним режимом; reduced motion.
- Створювати `table-generator` лише після перевірки спільного `data-row` та узгодження семантичної моделі даних.

## Критерій наступного кроку

Оболонка має залишатися незалежною від таблиць. Майбутня таблиця повинна змінювати лише власний вміст, модель і контекстну панель, а не створювати іншу навігацію або власну дизайн-систему.

## Автоматичні перевірки

- `src/core/preferences.test.js` — локальне збереження й відновлення уподобань без браузера.
- `tests/e2e/shell.spec.js` — Chrome: перемикання панелей, перемикання і збереження теми, мобільні шторки й Escape.
- `npm run test:e2e` — запуск Playwright із локальним Vite-сервером (Chromium попередньо інсталюється командою `npx playwright install chromium`).
- GitHub Actions перевіряє все при push у `work`. Не плутати автоматичні тести з остаточною візуальною оцінкою користувача.

## Візуальна ревізія 02 — 2026-11-05

Після зауважень щодо важких рамок переглянуто Shell без зміни модульних контрактів: прибрано декоративні блоки навколо вмісту, зменшено масштаб типографіки, зроблено рядки компактнішими, а перемикач теми — єдиним сегментованим контролом. Згортання лівої панелі змінює ширину плавно, права панель не зникає до завершення переходу. На вузьких екранах обидві шторки анімовані через transform, фон — через opacity; для reduced motion рух вимикається.

Успішна збірка не гарантує візуальну якість: Preview захищений авторизацією Vercel, фінальне оцінювання вигляду залишається за користувачем.


## Чотири кути — візуальне правило від legacy

Головний орієнтир — стриманий початковий дизайн Pinguin V5, а не окрема dashboard-естетика.
Не заповнювати простір рамками та картками без функціонального сенсу.

- **Верхній лівий:** круглий перемикач бічної навігації, зміна стану повертає іконку.
- **Верхній правий:** єдина кругла кнопка відкрити/сховати контекст; не дублювати кнопку закриття в самій панелі.
- **Нижній лівий:** круглий перемикач теми, послідовність system → light → dark; іконка рухається під час зміни.
- **Нижній правий:** зарезервовано для реальної швидкої дії поточного інструмента. **Не показувати порожню або нефункціональну кнопку.**

Кутові кнопки використовують один компонент \`pg-icon-button--corner\` і стандартні SVG. Рух при hover/click обмежений, з підтримкою \`prefers-reduced-motion\`. Стан/підпис доступні через ARIA, а теми зберігаються в \`pg:v1:shell:preferences\`.
