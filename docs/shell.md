# Pinguin Shell — принципи дизайну та поведінки

Стан: робочий прототип у гілці `work`. Оригінальний V5 залишається в `legacy`; `main` і `reserve` незмінні.

## Візуальна основа

- **Старий Pinguin V5 — основний референс**. Не перетворювати оболонку на dashboard із картками, декоративними блоками та великими вступами.
- **Єдиний фон** для лівої навігації й основної робочої області. Немає постійної кольорової перегородки між ними.
- Система **чотирьох кутів** залишається: верхній лівий — навігація, верхній правий — контекст, нижній лівий — тема, нижній правий — дії активного інструмента (тільки коли дії реальні).
- Кнопки керування — круглі, з невеликою анімацією іконок і доступністю через aria-label. Reduced motion вимикає рух.
- Без нефункціональних кнопок, повторних закривачів, зайвих заголовків та демонстраційних блоків.

## Панелі

- Ліва навігація — широка або вузька, займає простір у desktop layout, але має той самий фон, що й сторінка.
- На мобільному екрані навігація стає шторкою з затемненням позаду. Escape та backdrop закривають її.
- **Права панель за замовчуванням — плаваюче меню** з верхнього правого кута, без зміни ширини робочої області.
- **Кнопка піна — лише компактна іконка праворуч від «Проєкт» у шапці aside**, не окремий рядок меню. В активному стані вона має виділений фон і `aria-pressed=true`.
- Закріплення **не змінює вигляд або положення самого aside**: розмір, округлення, рамка, тінь і верхній правий відступ залишаються такими самими. На desktop змінюється тільки grid Shell: третя колонка (302 px) плавно відсуває центральну область.
- **«Відкріпити»** повертає меню у плаваючий стан. Закріплення зберігається у вподобаннях та не скидається переходом між сторінками або кліком поза панеллю. Верхня права кнопка може явно відкріпити й закрити панель.
- На мобільному закріплення вимкнено: меню залишається плаваючим незалежно від збереженого стану.
- Клік поза незакріпленим popover або Escape закриває його; для закріпленої desktop-панелі ці дії не спрацьовують. Перемикач у верхньому правому куті також його закриває.
- Поки немає модулів, поповер показує лише дві дійсні дії: посилання на код `work` та стандарт компонентів. Пізніше вміст визначатиме активний модуль.

## Тема — точна поведінка legacy

Перевірено у `legacy/js/components/ui-theme.js` та `legacy/js/theme-init.js`:

- Кнопка розташована внизу лівої навігації.
- Перемикається циклом **light → dark → system → light**.
- Системна тема динамічно реагує на `(prefers-color-scheme: dark)`.
- У режимі dark застосовується `data-theme="dark"`; у світлому — атрибут видаляється.
- Підтримується старий ключ `localStorage['theme-mode']`. Окремо оболонка використовує версійний ключ `pg:v2:shell:preferences` для станів панелей.
- Налаштувань теми в правому popover **немає**, аби не дублювати нижню ліву кнопку.

## Модульність та неймінг

- `src/shell/shell.js` — тільки життєвий цикл та події оболонки.
- `src/shell/sidebar` та `src/shell/aside` — незалежні частини.
- `src/core/theme.js` — логіка теми, яку можна тестувати без DOM браузера.
- `src/core/preferences.js` — локальний стан із захистом від помилок storage.
- `src/ui/button` і `src/ui/icon` — спільні кнопки й піктограми.
- Єдиний словник імен у [conventions.md](conventions.md); CSS-значення тем — тільки в `src/styles/tokens.css`.

## Перевірки

`npm run check` запускає модульні тести, аудит неймінгу та Vite build. У GitHub Actions також запускаються Playwright сценарії для desktop/mobile: стан навігації, компактний popover, позиції кутових кнопок, поведінка теми та reduced motion.

Візуальну оцінку має підтвердити власник сайту у Vercel Preview перед наступними змінами.

## Геометрія лівої навігації

Кнопка згортання, іконка пункту «Огляд» та кнопка теми мають незмінну вісь **28 px** від лівого краю в desktop-режимах. Відступи root sidebar та вкладені padding не змінюють центр іконок при згортанні/розгортанні. Мобільна шторка зберігає свою геометрію.
