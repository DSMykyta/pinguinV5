# Універсальний шаблон сторінок Pinguin Next

**Розміщення заголовків належить UI-системі, а не окремим інструментам.**

## Спільна структура

- `src/ui/page/page.js`: `createPageView({ title })` створює єдині `.pg-page`, `h1.pg-page__title`, `.pg-page__body`.
- `src/ui/page/page.css`: одна максимальна ширина 800 px, одне центрування, відступи й типографіка для будь-якої сторінки.
- `page.setTitle(title)` змінює тільки текст. Робочі модулі додають свій вміст у `page.body`.
- Не створювати `.pg-overview__title`, `.pg-tools__title` чи інші власні заголовкові стилі.

## Глобальна шапка

- `src/shell/shell.js` створює `.pg-shell__page-name` лише один раз.
- `src/shell/page-outlet.js` заповнює назву з маніфесту: «Огляд» чи «Інструменти».
- Активна вкладка викликає `setPageSection('Таблиці')` або `setPageSection('Текст')`: у тому самому місці відображається «Інструменти · Таблиці» або «Інструменти · Текст».
- Центрована навігація вкладок не замінює назву сторінки. Всі маршрути мають спільну шапку.

## Власність CSS

| Шлях | Відповідальність |
|---|---|
| `src/shell/shell.css` | Тільки глобальна оболонка, шапка, робоча область і кутові кнопки |
| `src/ui/page/page.css` | Однакові заголовки та геометрія сторінок |
| `src/ui/tabs/tabs.css` | Тільки локальні вкладки та анімація |
| `src/shell/sidebar/sidebar.css` | Тільки ліва навігація |
| `src/shell/aside/aside.css` | Тільки контекстне меню |
| `src/shell/route-message.css` | Тільки повідомлення маршрутизації |
| `src/styles/tokens.css` | Єдині значення тем, кольорів, відступів |

Інструменти визначають дані та вміст, а не власну геометрію шапки. Не додавати селектори `.pg-overview` або `.pg-tools` у `src/shell/shell.css`. Різні типи маршрутів не змінюють базові відступи сторінки.

## Перевірки

`tests/e2e/page-layout.spec.js` порівнює координати заголовків і шапки між «Оглядом», «Таблицями» та «Текстом» у desktop- і mobile-режимах, включно зі згорнутим sidebar та закріпленим aside.
