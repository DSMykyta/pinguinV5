# Універсальний шаблон сторінок Pinguin Next

Сторінки мають однакову оболонку; різні інструменти визначають тільки свій контент.

## Ієрархія

```text
Shell
├─ Sidebar (основні сторінки, тема)
├─ Workspace
│  ├─ Header: H1 — назва маршруту; справа — пошук і aside control
│  ├─ Local navigation: вкладки розділу, якщо вони є
│  ├─ Main
│  │  └─ Page View: H2 — назва секції, далі вміст
│  └─ Footer (hidden, поки порожній)
└─ Aside (floating / pinned)
```

Мобільний backdrop — службовий елемент Shell для відкритої панелі, **не** окрема зона документа.

## Незмінні правила

1. Заголовок маршруту H1 один, у Shell. Активний таб **не переписує** його.
2. Вкладки в глобальному слоті між шапкою та Main; не в sidebar, не по центру header.
3. Основна секція використовує `createPageView({ title })` з `src/ui/page/page.js`: H2 і `body`.
4. Однакова ліва вісь H1, вкладок та H2 задається токеном `--pg-workspace-gutter` у `shell.css`, без локальних винятків.
5. Робоча секція використовує доступну ширину (без фіксованого max-width: 800px), щоб майбутні таблиці не були штучно вузькими.
6. Пошук праворуч є спільним полем, а його індекс може розширюватися даними активної сторінки.
7. Footer завжди існує структурно, але доки порожній — `hidden` і не створює відступу чи лінії.

## Власники стилів

| Стиль | Файл |
|---|---|
| Глобальні п'ять зон, однакові gutter, шапка | `src/shell/shell.css` |
| Ліва панель | `src/shell/sidebar/sidebar.css` |
| Правий aside | `src/shell/aside/aside.css` |
| Верхній пошук | `src/shell/search/search.css` |
| Спільні текстові вкладки | `src/ui/tabs/tabs.css` |
| Заголовок секції й робочий контент | `src/ui/page/page.css` |
| Підказки | `src/ui/tooltip/tooltip.css` |
| Токени тем | `src/styles/tokens.css` |

У `shell.css` заборонені стилі конкретного інструмента або його внутрішніх компонентів. `npm run check:naming` перевіряє власність основних CSS-класів; Playwright перевіряє фактичну геометрію.

## Тимчасова перевірка меж (2026-11-05)

До затвердження геометрії `.pg-shell__content` тимчасово має світло-сірий фон (`--pg-color-hover`) і скруглення `18px`. Демонстраційний вміст вкладок `/tools` приховано, але логіка навігації та aside продовжує працювати. **Це лише режим перевірки**, не постійна палітра; після схвалення відновити прозору робочу область і вміст. Повернені погоджені метрики попереднього Shell: шапка `60px`, верхній padding основної області `40px` (desktop), її горизонтальні відступи `clamp(20px, 5vw, 72px)`; на телефоні `32px 20px 56px`. Праву групу кнопок тримати `position: fixed; top: 10px; right: 12px`, незалежно від закріплення aside. Зміна структури сторінки не дає дозволу змінювати ці значення.

## Оптичне вирівнювання в режимі перевірки

У `work` заголовок H1 і ряд вкладок мають спільний незалежний відступ `--pg-workspace-chrome-inset: 16px` від лівого краю центральної області. Внутрішній padding самої сірої робочої області **не змінюється** (`--pg-workspace-gutter` лишається колишнім). Права межа тимчасово сірої області відступає від docked aside на `--pg-aside-clearance: 16px`. Ліва навігація, позиція правих кутових кнопок, шапка 60px, анімації та поведінка aside не змінюються. Це точкове виправлення геометрії, а не нова система відступів.
