# Універсальний шаблон сторінок Pinguin Next

**Вигляд спільний, поведінка інструментів незалежна.**

## Один шаблон

- `src/ui/page/page.js`: `createPageView({ title })` створює спільні `.pg-page`, `h1.pg-page__title` та `.pg-page__body`.
- `src/ui/page/page.css`: максимальна ширина 800 px, центр, типографіка та відступи заголовка. Ці правила однакові на поточних вкладках.
- `page.setTitle(title)`: змінює заголовок без повторного монтування й власного CSS.
- Функціональні модулі створюють тільки вміст `page.body`. Для масштабних таблиць окремо обговоримо адаптивну ширину робочої області, але не дублюватимемо шапку.

## Заголовок і глобальне керування

- `src/shell/shell.js` створює `.pg-shell__page-name` зліва та спільні кнопки праворуч.
- `src/shell/page-outlet.js` підставляє назву маршруту та активної секції в тому самому місці.
- Локальні вкладки **не монтуються в header**. Їхній глобальний слот — `sidebar.localNavigation` під активним розділом.
- Глобальний пошук і кнопка контекстного aside — поруч справа у шапці на всіх маршрутах.
- Усі ці елементи не змінюють положення або типографіку `h1` конкретного інструмента.

## Власність файлів

| Файл | Відповідальність |
|---|---|
| `src/shell/shell.css` | Глобальна розкладка, шапка, чотири кути |
| `src/shell/sidebar/sidebar.css` | Основне ліве меню і місце для вкладок |
| `src/ui/tabs/tabs.css` | Стиль самих вкладок і адаптація за шириною контейнера |
| `src/shell/search/search.css` | Тільки пошук біля правої кнопки |
| `src/shell/aside/aside.css` | Контекстне меню |
| `src/ui/page/page.css` | Заголовки та геометрія сторінок |
| `src/shell/route-message.css` | Помилки маршрутів |
| `src/styles/tokens.css` | Кольори, відступи та основні значення дизайну |

Жодних CSS-винятків для конкретних сторінок в `shell.css`. Глобальна перевірка неймінгу стежить за власністю компонентних класів.

## Контроль

`tests/e2e/page-layout.spec.js` порівнює геометрію заголовків між «Таблицями» й «Текстом» на desktop/mobile та в режимі закріпленого aside.
